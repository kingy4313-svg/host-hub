# Anchor Sayanti

Create the same style web Project: Personal portfolio/booking website for an event anchor/host — "Sayanti Banerjee, Anchor Sayanti"

Overall Style: Luxury, elegant, dark-themed website with black backgrounds, gold/amber accents, and serif typography (like Playfair Display). Feels premium and celebrity-branded, similar to a high-end talent/booking site.

Global Design System
Color palette: Black (
#000000 / near-black) backgrounds throughout, gold/amber (
#D4A947 or similar) as primary accent color, white text for headings, light gray/blue-gray for body text
Typography: Elegant serif font (Playfair Display or similar) for headings/logo, clean sans-serif for body text and nav
Buttons: Pill-shaped/rounded, gold filled ("WhatsApp Now") and black/outline variants
Floating elements: A circular gold "Call" button fixed at bottom-right corner throughout the page
Section-by-Section Breakdown

1. Navbar (sticky top)

Left: Logo/name "Sayanti Banerjee" in bold serif
Center nav links: Portfolio, Past Events, About, Contact Me

Diagonal black cut-off shape at the bottom of the hero image (angled divider transition into the black content area)
